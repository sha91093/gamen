# 仮想ブラウザ スクリーンショットツール

Citrix仮想ブラウザ環境で、スクリーンショットの撮影・注釈・共有を**ブラウザ内だけで完結**させるツールです。

## なぜこのツールが必要か

| 問題 | 解決策 |
|------|--------|
| Snipping Toolはファイルを仮想ブラウザ外（ローカルPC）に保存してしまう | ブラウザ内のクリップボードに直接コピー |
| メール経由での共有が必要で手間がかかる | TeamsウェブやOutlookウェブに直接貼り付け |
| 注釈・ぼかしができない | ブラウザ内で矢印・テキスト・ぼかしを追加 |

---

## 2つの使い方

### 方法①：Webアプリ版（インストール不要・推奨）

`webapp/index.html` をブラウザで直接開くだけで使えます。

```
ブラウザのアドレスバーに以下を入力:
file:///path/to/webapp/index.html
```

または社内サーバーに配置してURLでアクセス。

**機能:**
- 🖥️ 現在の画面/タブを撮影（Screen Capture API使用）
- ✂️ 範囲を選択して撮影
- ✏️ ペン描画・矢印・四角形・テキスト追加
- 🔲 ぼかし（個人情報・機密情報の保護）
- 📋 クリップボードにコピー → Teams/Outlookウェブ版に貼り付け
- 💾 ファイル保存（仮想デスクトップ内）
- 📋 最近の履歴（ブラウザ内に最大12件保存）

---

### 方法②：ブラウザ拡張機能版（Chrome / Microsoft Edge）

より密なブラウザ統合。ツールバーにボタンが追加されます。

#### インストール手順

1. `extension/` フォルダをブラウザからアクセスできる場所にコピー
2. ChromeまたはEdgeのURLバーに `chrome://extensions/` または `edge://extensions/` を入力
3. 右上の **「デベロッパーモード」** をオンにする
4. **「パッケージ化されていない拡張機能を読み込む」** をクリック
5. `extension/` フォルダを選択

#### 使い方

- ツールバーの 📷 アイコンをクリック、または `Ctrl+Shift+S`
- 「現在のタブを撮影」または「範囲を選択して撮影」を選択
- 注釈を追加して「クリップボードにコピー」
- TeamsウェブやOutlookウェブで `Ctrl+V` で貼り付け

---

## 共有フロー

```
撮影 → 注釈追加 → 「クリップボードにコピー」
                              ↓
         Teams ウェブ版のチャット欄で Ctrl+V
         Outlook ウェブ版のメール本文で Ctrl+V
         SharePoint, Slack ウェブ版など...
```

すべて仮想ブラウザの外にファイルが出ることなく共有完了！

## ファイル構成

```
gamen/
├── webapp/
│   └── index.html          # Webアプリ版（これ1ファイルで動作）
└── extension/
    ├── manifest.json        # 拡張機能設定
    ├── background.js        # バックグラウンドスクリプト
    ├── popup.html           # ポップアップUI
    ├── popup.css            # スタイル
    ├── popup.js             # ロジック
    └── icons/               # アイコン画像
        ├── icon16.png
        ├── icon48.png
        └── icon128.png
```

---

## 注意事項

- Screen Capture API使用時、ブラウザが「共有する画面を選択」ダイアログを表示します（セキュリティ仕様）
- 組織のポリシーによってはブラウザ拡張のインストールが制限される場合があります → その場合はWebアプリ版をご利用ください
- 履歴データはブラウザのlocalStorageに保存されます（仮想ブラウザ外には出ません）
